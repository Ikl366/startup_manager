# startup_manager

**Removal of "ghosts"** —  tool for detecting and terminating processes that run in the background without appearing in the standard start-up lists.

---

##  Description
Have you ever noticed that your computer sometimes carries out tasks without your knowledge, even though there’s nothing suspicious in the start-up list? If not, be aware that something is definitely running in the background. 

`startup_manager` helps you visualise these ‘invisible’ processes and gives you control over them.
